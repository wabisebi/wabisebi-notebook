# Wabisebi Japanese

A personal Japanese grammar site for Seb. One page per grammar point, added after we talk the point through until it clicks. Plain HTML, no framework. Inside Claude it's previewed through a tiny local server (see Preview below); outside Claude Seb can still just open `index.html` in Safari or Chrome.

## Goal
Understand every N5 grammar point and have each one here as a page (set 23 Oct 2026). Seb does Bunpro lessons alongside, but these pages are where it actually clicks. New grammar pages come first; side features (soundboard, themes, tooling) wait unless they directly help.

## How we work
- Talk a grammar point through first. Only add to the site what actually helped in the conversation.
- Every page must make sense on its own. If a rule from another page applies (for example when to add な), repeat it on this page. Cross-links are a bonus, never a replacement.
- To check the site, start the preview with `preview_start` name `notebook` (Python's built-in server on port 8000, nothing to install, costs no tokens while running). It shows the full site in the browser pane, images and audio included. Rebuild first so `index.html` is current. Only take screenshots for layout changes.
- Seb wants to see the full working site (with media) inside Claude, so use the preview server rather than opening files directly. Don't add other servers, frameworks or build tools without asking.
- Only edit the page being worked on. Never change other pages unless Seb asks.
- Don't add new section types (rules, frames, warnings) on your own. Suggest first, add only when Seb says yes.
- The site-wide structure and consistency pass happens later, only when Seb asks.
- Never use em dashes in anything written for Seb, on the site or in replies.
- Never use Seb's name (Seb, セブ) in examples on the site (8 Nov 2026). Use a common Japanese name like 山田 or 田中 instead.
- Never copy sentences or examples from other sites (Bunpro etc.). Seb shares them only to show what clicked. Write our own.
- Keep replies direct, short and informal.

## Page structure (current)
Each grammar point is its own file in `pages/`. To make a new one, copy an existing page, keep the shell (head, `<header class="top">`, `<main>`, foot, `site.js` script) and replace the `<article id="...">`. Inside the article:
- `.head`: small label (for example "N5 Grammar"), the pattern, and an empty `<p class="sub"></p>`. `site.js` fills it with the short description from `INDEX` ("Object marker", "To be, is (polite)"), the same text as the grid card. Never type the description into the page; change it in `INDEX` only, so both always match. No gist line, the lead card does that job. `site.js` also puts a "◀ All grammar" pill button (`.back`, the play button's triangle pointing left) just above the card on the left, back to the grid (added 29 Oct 2026); nothing to add by hand.
- Two forms cheatsheet (added 29 Oct 2026): a `.forms.twoforms` box right under `.head`, before the lead card, so it's clear at once there are two forms. Same table look as the family table, but just two rows: `<span class="use polite">Polite</span>` and `<span class="use casual">Casual</span>` with the forms, then a short `.m` line ("Same meaning: ... Only the politeness changes."). Only on pages where the grammar point itself has a polite/casual pair (31 pages since 29 Oct 2026, plus ましょう on 1 Nov 2026: the First steps pairs, 誰/どなた, どちら, どう, どうして, と (quote), the adjective pages, the verb form pages, 来る, する, たい, ほしい, ませんか, ましょう, ましょうか, つもり, けど, の, んです). Exception: この・その・あの has one (1 Nov 2026, Seb asked), showing only the ending changes, because its cards come in both kinds. Pages where the politeness only comes from です/ます at the end (particles, は, これ, でしょう, から, ので, adverbs etc.) get NO box (removed from 77 pages on 6 Nov 2026, Seb agreed: it took a lot of room to say "nothing changes", and the Polite/Casual labels on the cards already show it). So the box only appears when there really is a pair. Not on さ and ～な (Don't), which are casual only, nor on ます, which is polite only (removed 1 Nov 2026, Seb asked). The three adjective negative pages got a real pair box instead (1 Nov 2026). Add one to every new page that has a real pair. Grammar only, never a sample word (Seb, 1 Nov 2026): write the pattern with ～ (～ます / ～る・～う, ～ましょう / ～よう・～おう), and say how it's built in a `.hint` when needed ("drop る, add ます"). A real word is fine only when the word IS the grammar point (です, ある, する, 来る, いい, どなた...). Exception: when the form depends on the verb's last sound, the box is an "Ends in" table with one sample verb per row (Ends in / Verb / Polite / Casual, `th.ends`), as on う-verb past (1 Nov 2026, Seb asked). Our own sample verbs, not Bunpro's. When a row has more than one form, each form gets a short grey `<span class="hint">` after it saying when to use it (29 Oct 2026, e.g. じゃないです "everyday, softer", じゃありません "standard polite, a bit firmer", ではありません "most formal: news, speeches, writing"); a thin line separates the table from the `.m` note.
- "A verb alone can be a sentence" box (9 Nov 2026, Seb asked, only on る-Verb and う-Verb Dictionary so far): a `.vsolo` box right under the two lead cards (these two pages have no "With and without" section, Seb removed it) with 3 `.vcard` clips from the local shows where the verb is the whole line.
- Lead card (every grammar page has one since 22 Oct 2026): a `.lead` box right under `.head`. A `.use` Polite/Casual label first (every lead with a sentence, 2 Nov 2026, Seb asked), then screenshot, `.src`, a `.line` with `.play` + a short `.jp` sentence, `.en` with implied context in `<span class="ctx">[brackets]</span>`, then `.explain`.
  - Only Seb's OWN mined cards (same Migaku cards and media as sentence mining). Never use cards or media from the Jlab deck; it was only the inspiration.
  - Just pick the BEST cards (changed 23 Oct 2026): clear, natural, short. It doesn't matter where in the sentence the grammar is, or if other grammar comes after it (よ, けど, んで, の, etc. are all fine). Search the Sentence field. Later grammar can use longer sentences. Don't repeat the same card in Sentence mining below.
  - `.explain` order (31 Oct 2026): the rule first, then the sentence about the clip starts with "On this card," (so it doesn't jump abruptly to the scene). Don't repeat the polite/casual forms the top box already shows, and don't open a second card with "Casual version:" (its `.use` label says that).
  - `.explain` must clearly DESCRIBE the grammar, not hint at a feeling: what it does, what it attaches to, what question this sentence answers, then the polite/casual (or other) variant. 3 short sentences, plain words, our own wording.
  - Polite and casual forms of the same grammar live on ONE page (decided 22 Oct 2026, no exceptions; です and だ were split for a while and merged back). Not an exception but worth knowing: でしょう and だろう are two pages (23 Oct 2026), because in speech the real split is neutral でしょ vs masculine だろ, not polite vs casual. でしょう and でしょ share the でしょう page. If a point has another form, add a second card right under the first: `.lead.second`, its own real clip, a `.use` label ("Polite"/"Casual"), and only 1 or 2 sentences of `.explain`. The first card then gets a `.use` label too. Now on です / だ, ～の, ～んです, い-adj past.
  - New pages always get one. If no own card fits, ask Seb instead of using someone else's.
