# N4 checklist

Every N4 grammar point we plan to have in the notebook, sorted into categories in learning order.
`[x]` = has a page. Tick a point when its page is added.

There's no official JLPT list, so this is our own (made 13 Nov 2026), merged from memory of the common unofficial N4 lists. Points those lists call N4 but the site already has as N5 pages are left out (たり, あげる・くれる・もらう, すぎる, 方がいい, 時, 前に, 後で, つもり, ことができる, たことがある, なくてはいけない...).

The N5 checklist's "Maybe N4" section (なくてもいい, ながら, という, など) and its parked ～ようになる are listed here too. Tick them in both files.

Categories marked *(new)* aren't on the site yet. They get added to `INDEX` when their first page is made.

## Particles
- [x] とか: things like, or something
- [x] Particle + の: との, での, からの
- [x] など: and so on
- [x] でも: even (子どもでも分かる)
- [x] ばかり: nothing but
- [x] までに: by (a deadline)
- [x] も (with numbers): as many as
- [x] ずつ: each, at a time
- [x] って: casual は / casual と (quoting)

## Sentence endings
- [x] かな: I wonder
- [ ] かしら: I wonder (softer)
- [ ] っけ・だっけ: what was it again?
- [ ] じゃない (confirming): isn't it? see?

## Guessing and seeming
- [x] はず: should be, expected to be
- [x] みたい: seems like, looks like
- [x] ～たつもり: believing you did
- [ ] かもしれない: maybe, might
- [ ] ～そう (looks): looks like it's about to, looks tasty
- [ ] ～そうだ (heard): I heard that
- [ ] らしい: apparently, I hear / typical of
- [ ] ようだ: it seems (more formal みたい)
- [ ] はずがない: can't possibly be
- [ ] ～がする: there's a smell, sound, feeling

## Adverbs
- [x] こんなに・そんなに・あんなに: this much, that much
- [ ] なかなか～ない: just won't, not easily
- [ ] ずっと: the whole time / by far
- [ ] きっと: surely
- [ ] ぜひ: by all means

## Comparing *(new)*
- [ ] ～ほど～ない: not as ... as
- [ ] AとBとどちらが: which is more, A or B
- [ ] ～と同じ: the same as
- [ ] ～のように・～のような: like, as

## Joining sentences
- [x] のに: even though
- [x] ～し: and also, listing reasons
- [ ] ～ても: even if
- [ ] Question word + ても: no matter what, who, how
- [ ] ～ながら: while
- [ ] ～ないで: without doing
- [ ] ～ずに: without doing (written)
- [ ] ～て (reason): because (疲れて寝た)
- [ ] ～ため(に): in order to / because of
- [ ] ～ように: so that
- [ ] ～のに (purpose): for, in order to

## If and when *(new)*
- [ ] ～たら: if, when
- [ ] ～ば: if (conditional form)
- [ ] ～と: whenever, if (always happens)
- [ ] ～なら: if that's the case

## Time *(new)*
- [ ] ～ところ: about to, in the middle of, just did
- [ ] ～たばかり: just did
- [ ] ～間・～間に: while, during
- [ ] ～うちに: while (before it changes)
- [ ] ～たまま: leaving as it is
- [ ] ～始める・～出す: start doing
- [ ] ～終わる: finish doing
- [ ] ～続ける: keep doing

## Verb forms *(new)*
- [ ] Potential form: can (食べられる, 書ける)
- [ ] Volitional form: let's (casual), 食べよう
- [ ] ～ようと思う: I think I'll
- [ ] Passive form: was done (by someone)
- [ ] Causative form: make, let someone do
- [ ] Causative-passive form: be made to do
- [ ] Imperative form: do it! (rough)
- [ ] ～なさい: do it (parent, teacher)

## て-form
- [ ] ～てしまう・～ちゃう: end up, finish completely
- [ ] ～てみる: try doing
- [ ] ～ておく: do in advance
- [ ] ～てある: has been done (and stays)
- [ ] ～ていく・～てくる: go on doing, come to
- [ ] ～てほしい: want someone to
- [ ] ～てもかまわない: it's fine if
- [ ] ～なくてもいい: don't have to
- [ ] ～なければならない・～なくちゃ: must (check the N5 page なくてはいけない first, it may belong there)

## Asking and giving *(new)*
- [ ] ～てくれませんか・～てもらえませんか: could you?
- [ ] くださる・～てくださる: give (respectful)
- [ ] いただく・～ていただく: receive (humble)
- [ ] ～ていただけませんか: could you please?
- [ ] やる: give (to animals, plants, younger)

## Changes and decisions *(new)*
- [ ] ～ようになる: come to, become able to
- [ ] ～ようにする: make sure to, try to
- [ ] ～ことにする: decide to
- [ ] ～ことになる: it's been decided that
- [ ] ～ことがある: there are times when

## Easy, hard, how to *(new)*
- [ ] ～やすい: easy to
- [ ] ～にくい: hard to
- [ ] ～方: how to (作り方)
- [ ] ～さ: adjective to noun (高さ)
- [ ] ～がる: someone else seems to feel (寒がる)
- [ ] ～たがる: (someone else) wants to

## Quoting and asking *(new)*
- [ ] という: called, named
- [ ] ～ということ: the fact that, that means
- [ ] ～か (inside a sentence): (I don't know) when, what
- [ ] ～かどうか: whether or not
- [ ] ～ように言う: tell someone to

## Turning into a noun *(new)*
- [ ] ～こと: doing X (as a thing)

## Polite speech (Keigo) *(new)*
- [ ] Respectful verbs: いらっしゃる, おっしゃる, 召し上がる
- [ ] Humble verbs: 参る, 申す, いたす
- [ ] お～になる: respectful pattern
- [ ] お～する: humble pattern
- [ ] ございます: very polite ある
