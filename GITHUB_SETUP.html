GitHub setup

How my notebook syncs between the MacBook and the Mac mini. Set up 23 Oct 2026.

The three words

Commit = make a save. Like a save point in a game. It happens on the computer I'm using.

Push = send my saves to GitHub.

Pull = get the newest saves from GitHub onto the computer I'm using.

GitHub is a website that keeps a copy of my saves online. My spot there is private, so only I can see it: github.com/wabisebi/wabisebi-notebook

Every time I work

1. Sit down: tell Claude "pull".

2. Work on the notebook.

3. Done: tell Claude "commit and push".

Same on both computers. If I forget to push, the other computer won't have my work. If that happens, Claude can fix it.

What we set up on the MacBook

1. The folder can save versions. The saves live in a hidden folder called .git inside the notebook folder. To see it in Finder: Cmd + Shift + . (period). Never delete it, the saves would be gone.

2. My spot on GitHub. I made it myself on github.com: private, empty, no README.

3. Permission. My MacBook logged in to GitHub once with a one-time code, so GitHub knows the saves really come from me. GitHub showed a page saying "Authorize GitHub CLI": that's the small official GitHub tool Claude installed on my Mac.

4. First push. My notebook went to GitHub. On the GitHub page I can click "commits" to see every save with its note and date.
